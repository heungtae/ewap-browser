작업 승인

아래 설정은 ‘작업 설정 저장’을 눌러 적용합니다. 저장하면 진행 중인 작업이 취소됩니다.

모두 자동 승인은 요청한 작업의 실행·권한·자료 전송 승인을 자동 처리합니다. 입력값·대상 선택과 Chrome 권한이 필요한 경우에는 안내합니다.
