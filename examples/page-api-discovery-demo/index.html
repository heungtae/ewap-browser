Page API Discovery fixture

doc 29의 정적·비실행 discovery 경계를 확인하는 로컬 테스트 페이지입니다. 이 페이지의 함수와 endpoint-like 문자열은 모두 가짜이며 호출되지 않습니다.

확장 프로그램 Side Panel에서 API를 눌러 scan하세요. 결과에는 redacted 후보 분류만 나타나야 하며, 경로·함수명·반환값은 나타나거나 실행되면 안 됩니다.

허용 root: own data descriptor

appData, gridApi, demoControls에 one-level public 함수 형태를 제공합니다. 실행용 API가 아니라 hint용 shape입니다.

제외돼야 하는 입력

allowlist 밖 privateBackdoor, getter, hostile Proxy와 external script는 후보나 오류 상세로 노출되면 안 됩니다.

Inline endpoint hint

아래 inline dormant 코드에 literal 호출 형태가 있습니다. 네트워크 요청은 발생하지 않고 scan은 URL 대신 저신뢰 hint만 반환해야 합니다.

경계 확인 조작

초기 상태: inline script budget 안입니다. scan 뒤 oversized script를 추가하면 다음 scan은 truncated여야 합니다.

기대 결과

  • 공개 함수 hint: medium confidence, own-data-descriptor / function-shape evidence
  • inline literal endpoint hint: low confidence, raw URL이나 source는 표시하지 않음
  • external script의 literal과 allowlist 밖 root는 후보에 포함하지 않음
  • getter / Proxy 오류는 상세 없이 생략하고, 함수 호출·HTTP 요청·storage 변경은 하지 않음
