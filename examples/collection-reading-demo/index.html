Collection Reading Test Pages

These pages demonstrate different collection types that the collection reader can handle.

Static Table

A regular HTML table with all rows in the DOM. Tests StaticTableListReader.

Virtual Scroll Grid

A grid with virtual scrolling (only visible rows rendered). Tests VirtualScrollReader.

ARIA List

An ARIA listbox with listitems. Tests StaticListReader.

SVG Chart

An SVG chart with accessible data labels and a data table. Tests SvgChartReader.

Canvas Chart

A Canvas chart (viewport only, no data extraction). Tests CanvasChartReader.

Pagination

A paginated table with next/prev controls. Tests PaginatedReader (stub).

Mixed Collections

A page with multiple collection types. Tests discovery and selection.

Collection Fixture (for Adapter)

A page matching the fixture data adapter (collection-fixture in path, role=grid). Tests ReviewedSiteDataReader with fixture adapter.
