# 비규범 참고자료

이 디렉터리의 문서는 배경 이해와 비교 검토를 위한 읽기 전용 자료다.

다음 용도로 사용하지 않는다.

- 제품 요구사항 또는 설계 계약
- 개발 범위와 구현 방식의 결정
- Sprint 계획, 완료 조건 또는 진행 상태의 근거
- 테스트 케이스, acceptance criteria 또는 release 판단의 근거
- 현재 설계 문서와 코드 사이의 traceability 근거

현재 제품의 규범적 계약은 상위 디렉터리의 번호가 붙은 설계 문서와 `sprints/` 문서에서만 확인한다. 참고자료와 규범 문서가 충돌하면 규범 문서가 항상 우선한다.
