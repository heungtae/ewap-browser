CONTEXT PILOT / User guide

Your browser, with a helping hand.

Ask questions about the page you are reading. Act on a task with consent and review. Connect the model provider you choose.

Get started →

Install ContextPilot

You need Chrome 116 or later. To build from source, install Node.js 20 or later and use pnpm@9.15.4. Run these commands from your repository clone: 

corepack enable
pnpm install --frozen-lockfile
pnpm exec tsc -p tsconfig.build.json
node scripts/build-extension.mjs
pnpm validate:package
  1. Open chrome://extensions and turn on Developer mode.
  2. Click Load unpacked and select dist-extension/ inside the repository.
  3. Open the extension's options page (Settings) to configure your model provider.
  4. Visit a web page and open the ContextPilot side panel.

For a local ZIP, build with node scripts/build-extension.mjs --release, then run pnpm package:local. Extract dist/contextpilot-<version>.zip and load the extracted folder. This is an unpacked installation, not a Chrome Web Store install.

Default builds retain unmasked development diagnostics. The --release build masks diagnostics and is required for ZIP packaging. The commands above preserve the extension version. pnpm build, pnpm build:release and pnpm test increment it.

Connect a model provider

  1. In Settings → LLM Provider, enter a Provider ID and select the matching Plugin.
  2. Enter your provider's Endpoint and Model. Choose the supported Wire API: Auto, Chat Completions, or Responses.
  3. Select the authentication method and enter your API key in the secret field if required. Add HTTP headers only when your provider needs them.
  4. Save the configuration and run the connection test. In provider management, select the provider you want to use.

For HTTP endpoints, request HTTP host access. Private IPv4 endpoints also require the private-network opt-in. Check your provider's API documentation for the endpoint, model, and authentication format.

Configuration is stored in the current Chrome profile. Page context approved for a request can be sent to the selected provider; a remote model does not run locally just because the extension does.

Ask about a page

  1. Open the page you want to discuss and the ContextPilot side panel.
  2. Select Ask and enter a question, such as “Summarize this page and list its main points.”
  3. Review any page, source, or screenshot access prompt before granting consent.
  4. Read the answer and continue in the same conversation. Check important conclusions against the original page.

For tables or lists, try “Read the visible table and compare the values.” Available data depends on the page, access permissions, and supported tools. Use the page-data controls when you need to select a source.

Carry out a browser task

  1. Select Act on the page where the task should begin.
  2. Describe the goal and exact values: “Enter ContextPilot in the search field and show the results.”
  3. Follow the plan and action review prompts shown in the side panel. Inspect destinations and values before approving.
  4. Watch execution details and the resulting page. Use Stop to cancel an active request.

If the page changes or the target cannot be identified, follow the new observation or selection prompt. A task may be blocked or incomplete; inspect the final status and actual page before assuming it succeeded.

Permissions and privacy

Review approval settings in Settings and grant access only for the task you intend to perform. Follow the actual UI for page access, source or vision sharing, and consequential actions. You can revoke saved permissions in Settings, then verify the effect with a new request.

Keep API keys in the secret fields. Do not include keys, authentication headers, or raw sensitive page content in shared configurations or support reports. Before exporting diagnostics, inspect the material you plan to share.

When an organization manages the extension, contact your administrator about required services or policy restrictions.

Update or roll back

  1. Close Chrome and back up the current extension folder.
  2. Replace the contents at the same path with the new unpacked ZIP.
  3. Restart Chrome and check the extension version, Settings, provider connection, and permissions.
  4. To roll back, close Chrome and restore the previous package at the same path.

A different installation path may change the extension ID and storage. Conversations use browser-session storage; do not rely on them surviving a Chrome restart. Record the version and installation path before an update.

Troubleshooting

The extension will not load
Use Chrome 116 or later and choose the folder containing the built manifest.json, not the repository root or the ZIP itself.
The provider connection fails
Check the plugin, endpoint, wire API, model, authentication, and host permissions. Run the connection test again after saving changes.
Page data or an action is unavailable
Check the current tab and access prompts. Inspect the execution details for a denied permission, stale page, unsupported target, or provider error, then start a new request when appropriate.
You need to report a problem
Record the extension version, Chrome/OS, reproduction steps, expected result, and actual result. Remove sensitive values from screenshots and diagnostics.
