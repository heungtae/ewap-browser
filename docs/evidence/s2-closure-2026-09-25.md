## 재검증 중 수정과 범위

기존 bounded CDP 경로에 tab별 marker 복구와 abort·quarantine, dispatch 직전
권한 재확인, editable/viewport preflight, 고정 Ctrl+A text 교체를 연결했다.
Stop·permission 철회·navigation·tab close가 실행 중 CDP를 중단한다.
fixture select의 정확한 option 결과와 stale ref 오류 코드도 보정했다.

`pnpm check:source-size`는 기존 저장소 baseline의 200줄 초과 파일들로
exit 1이다. 이 변경 전 `bounded-adapter.ts`도 336줄로 이미 초과했고,
현재 463줄이다. 새 S2 runner와 새 recovery/test 파일은 각각 200줄
미만이다. 이 규칙은 S2 종료 계약의 gate가 아니며 저장소 차원의 정리
과제로 남는다.

fixture는 자체 서명 HTTPS를 Chrome의 `--ignore-certificate-errors`로
허용한다. R2 submit은 통제 fixture의 결과적 버튼 행동이며 실제 서버
write를 수행하지 않는다. 운영 사이트·실제 Provider, 일반 Profile Act,
detach 실패의 실제 Chrome 강제 주입, Windows와 release readiness는
이 판정의 증거가 아니다.
