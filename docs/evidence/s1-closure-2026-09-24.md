## 재검증 중 수정

기존 `ProfileResolver`가 주입된 `fetch`를 인스턴스 메서드로 호출하여
Chrome Service Worker에서 `Illegal invocation`이 발생했다. Worker global을
receiver로 지정하고 Resolver 요청의 `credentials: "omit"`을 명시했다.
Unit test에서 두 조건을 고정하고 위 Chrome 시나리오로 정상/손상 JWS를
다시 확인했다.

fixture는 임시 자체 서명 인증서를 Chrome의 `--ignore-certificate-errors`로
허용한다. 결과는 통제 fixture에서의 경계 증거이며 인증서 신뢰 체인,
운영 Resolver·Provider 및 실제 로그인 사이트 전체 조합을 증명하지 않는다.
