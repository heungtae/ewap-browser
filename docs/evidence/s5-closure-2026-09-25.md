| UI-001 | 실제 HTTPS Provider가 1글자 SSE delta 1,000개를 전송했다. 실제 Panel assistant text가 기대한 1,000자와 정확히 일치했고 Provider 호출은 1회였다. Worker는 delta를 32ms/4,096자 단위로 합쳐 ChatEvent로 발행한다. |

`pnpm test:chrome-s5`는 격리 Chrome profile·자체 서명 HTTPS fixture를
만들고 종료 시 정리한다. 실제 Provider stream/worker/Panel lifecycle을
먼저 검사한 뒤 같은 Side Panel에서 불가능하거나 위험한 late/duplicate
event를 통제 주입으로 검사한다. 주입 단계의 card 결과를 실제 Provider의
tool call 결과로 주장하지 않는다.

## 증거의 경계

200% 확인은 CDP `Emulation.setPageScaleFactor(2)`와 320 CSS px에서의
레이아웃·focus 확인이며 Chrome 설정의 페이지 확대나 axe 전체 감사는
실행하지 않았다. 운영 Provider, 실제 회사 사이트, Windows, 외부 접근성
인증, screenshot/annotation schema, 전체 en-US 번역과 배포 승인은
이 Linux 로컬 S5 판정에 포함하지 않는다.
