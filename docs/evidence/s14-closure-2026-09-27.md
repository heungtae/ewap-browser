## 구현·음성 검증

- 저장된 기록의 origin과 path segment를 현재 페이지에 대조한다.
  `/trend`는 `/trend/view`에 일치하지만 `/trending`에는 일치하지 않는다.
- top-frame `all_dom`, `truncated=false`, 정확한 node count, 최대 500개 node의
  snapshot만 비교한다. 범위·완전성 조건이 부족하거나 저장 fingerprint가
  canonical 43자 base64url SHA-256 형식이 아니면 `incomparable`로 처리한다.
- 비교 가능한 fingerprint가 같으면 `verified`, 다르면 `stale`로 표시한다.
  `stale`과 `incomparable`은 후보 선택을 차단한다. `verified` 후보도
  선택과 시작 시 저장 기록과 최신 페이지 snapshot을 다시 비교한다.
