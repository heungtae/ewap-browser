# S22 OpenRouter 무료 모델 live 검증 — 2026-10-12

**S22 구현·검증 진행 중 유지.** 무료 모델로 실제 Chrome/Provider 검증을 실행했지만
전체 C1~C8/R1~R18 qualification을 완료하지 못했다. 최초 실패와 재실행은
[JSON 증거](s22-live-free-2026-10-12.json)에 모두 보존한다.

- Worker bundle SHA-256: `96cfbbc8f4d578e38f17cd76cb2b46a94a569f8732c3d7e0d9d98f6874e33aa3`.

  증거에 저장하지 않고 tool 이름/call ID/결과 metadata/hash를 보존했다.

  Chrome host permission은 기존 harness의 격리 profile 설정을 사용했다.
  Chrome 자체 권한 prompt의 사용자 승인은 이번 검증 범위가 아니다.

| Laguna 혼합 cedar/ridge               | 0/2 PASS                | cedar 최초 호출 429; ridge는 실제 도구 3종 제안 후 후속 호출 429                                                   |

HTTP 성공을 semantic PASS로 취급하지 않았다. 최초 실패는 재실행 성공으로 삭제하지 않는다.
holdout normal의 최초 report에는 판정 이후 도착한 `report_goal_status:completed`도 남아 있다.
기존 driver가 `recent.length >= 2`와 Panel의 일시적인 idle만으로 종료했기 때문이다.
[ISS-20261012-003](../issues/records/2026-10-12-s22-live-driver-settlement.md)에서
proxy 응답 완료와 structured goal을 기다리도록 수정했다. 제품 코드와 버전은 유지했다.
generic-unchanged/delayed의 최초 실패는 추가 live 재검증이 막혔으므로 제품 원인으로
확정하거나 해결로 승격하지 않는다. 혼합 TypeError의 세부 원인도 미확정이다.

## 재현

버전 보존 빌드·package validation PASS:

```sh
pnpm exec tsc -p tsconfig.build.json
node scripts/build-extension.mjs
node scripts/validate-package.mjs
```

`CHROME_FOR_TESTING_BIN`을 Chrome for Testing 실행 파일로 설정한 뒤:

```sh
S22_REPORT=/tmp/s22-controlled.json pnpm test:chrome-s22
S22_LIVE_MODEL=nvidia/nemotron-3.5-lightning:free \
  S22_CASES=normal,already,blocked S22_REPORT=/tmp/s22-basic.json pnpm test:chrome-s22
S22_LIVE_MODEL=nvidia/nemotron-3.5-lightning:free \
  S22_CASES=generic-click,generic-unchanged,element,delayed,replacement,not-completed \
  S22_REPORT=/tmp/s22-extended.json pnpm test:chrome-s22
S21_VARIANT=1 S22_LIVE_MODEL=nvidia/nemotron-3.5-lightning:free \
  S22_CASES=normal,already,blocked S22_REPORT=/tmp/s22-holdout.json pnpm test:chrome-s22
S21_VARIANT=1 S22_LIVE_MODEL=nvidia/nemotron-3.5-lightning:free \
  S22_CASES=normal S22_REPORT=/tmp/s22-holdout-recheck.json pnpm test:chrome-s22
S22_LIVE_MODEL=nvidia/nemotron-3.5-lightning:free \
  S22_CASES=generic-unchanged,delayed,not-completed \
  S22_REPORT=/tmp/s22-extended-recheck.json pnpm test:chrome-s22
S22_MODE=full S20_LIVE_MODEL=nvidia/nemotron-3.5-lightning:free \
  S20_REPORT=/tmp/s22-mixed.json node --experimental-websocket scripts/chrome-s20-mixed-smoke.mjs
S22_MODE=full S20_LIVE_MODEL=poolside/laguna-s-2.1:free \
  S20_REPORT=/tmp/s22-mixed-laguna.json node --experimental-websocket scripts/chrome-s20-mixed-smoke.mjs
```

driver syntax/Prettier 검사와 Node globals를 명시한 ESLint 검사 PASS.
기본 ESLint 직접 실행은 scripts의 Node globals 설정 부재로 실패했으며 제품 오류로
해석하지 않는다. 전체 unit/typecheck/lint suite는 재실행하지 않았다.

## 남은 범위

무료 endpoint 제한 해소 후 driver 수정본으로 추가 실패 3건과 혼합 흐름을 재검증해야 한다.
category별 ask/auto/deny 전체 matrix, migration/race/restart/Stop/자료·vision·scroll 경계,
R1~R18 전체 runtime 증거는 이번 smoke 표본으로 대체할 수 없다.
운영 사이트·Platform·배포는 실행하지 않았다. OpenAI 키가 실행 환경에 없었으며
이번 요청의 무료 OpenRouter 검증 범위에서 다른 유료 모델로 전환하지 않았다.
