# S6-R Collection Reading Browser Closure Evidence

- Date: 2026-10-01
- Scope: Browser-local collection reading and Ask/Act analysis reinjection.
- Browser: Chrome for Testing 154.0.8037.57, headed under Xvfb with Xfce window manager.
- Provider: controlled local HTTPS OpenAI-compatible fixture. No production provider was contacted.

## Implementation checked

- Ask and Act return a Side Panel choice when a request cannot safely distinguish among multiple collections.
- Selection and one-request `collection_read` approval resume the existing chat request. The worker rediscovers the page and rebinds the selected descriptor before reading.
- Collection records are bounded and sanitized before the selected source is inserted into `[UNTRUSTED_ANALYSIS_DATA]`.
- A reviewed fixture adapter is registered for one exact HTTPS origin and pathname, with a closed result schema and bounded cursor, stable IDs, total, and EOF evidence.
- Virtual scrolling dispatches the container scroll event, waits for the mounted window to settle, and restores the original position.

## Chrome evidence

Command used for each headed Chrome test:

```sh
CHROME_FOR_TESTING_BIN=/tmp/chrome-linux64/chrome xvfb-run -a sh -c 'xfwm4 --compositor=off >/tmp/xfwm4.log 2>&1 & npm run test:chrome-collection'
CHROME_FOR_TESTING_BIN=/tmp/chrome-linux64/chrome xvfb-run -a sh -c 'xfwm4 --compositor=off >/tmp/xfwm4.log 2>&1 & npm run test:chrome-analysis-data'
```

Results:

- `test:chrome-collection`: passed with 1,000 collected logical rows, total/EOF evidence, 200-record result chunk and `restored_position=true`; the fixture returned to `scrollTop=0`. A second run was stopped after progress and returned `coverage=partial`, `reason=CANCELLED`, 84 collected rows and `restored_position=true`; the fixture again returned to `scrollTop=0`.
- `test:chrome-analysis-data`: passed for unique-source Ask/Act and for ambiguous multi-source Ask/Act. Each multi-source flow selected the second table, approved one-request access, resumed, and delivered `SELECTED_BETA` in the collection analysis block without `UNSELECTED_ALPHA` in that block.
- The fixture's ordinary page projection can still contain visible page text from both tables. The selected-source assertion applies to the separately marked collection analysis block, which is the reader reinjection boundary.
