## First failure and correction

The first MV3 attempt failed during local preparation, before a remote policy put. The shared CDP helper returned a rejected Promise's error object without surfacing the exception, so the next journal validation initially reported `MIGRATION_JOURNAL_INVALID` with an undefined digest. Added page-readiness checks and explicit fixture error assertions exposed the underlying `unsafe-eval` CSP rejection: pinned Zod's eval probe/JIT path was incompatible with the actual MV3 execution context. Earlier loopback page checks did not establish MV3 CSP behavior.

[Browser schema configuration](../../apps/chrome-extension/src/bridge/schema-config.ts) now selects Zod's supported `jitless` mode before schema initialization in Worker/presentation/fixture entrypoints. Extension CSP was not relaxed. The corrected actual Chrome run records **zero CSP violations** and passes the real transport path. Draft artifact outputs remain local; retained artifacts/report identify the final CSP-safe build.
