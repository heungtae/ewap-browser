## 범위와 남은 한계

`pnpm check:source-size`는 기존 저장소의 200줄 초과 파일 때문에 여전히
exit 1이다. 새 S3 runner·unit 파일과 수정된 Provider runtime(195줄)은
200줄 미만이며, 기존 `bounded-adapter.ts`는 type 추출 후에도 446줄이다.

fixture의 인증서는 Chrome의 `--ignore-certificate-errors`로 허용한다.
원문 API key는 core transport가 사용하기 위해 `chrome.storage.local`의
비공개 Provider 설정에 저장된다. 위 비노출 판정은 공개 응답·export·진단과
Provider 요청 body에 관한 것이다. 실제 Provider별 호환성, 운영 자격증명,
구형 `type: "openai_compatible"` 저장값의 자동 이전, plugin 설치 영속화,
Windows와 release readiness는 이 증거로 주장하지 않는다.
