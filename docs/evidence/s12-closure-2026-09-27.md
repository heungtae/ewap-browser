# S12 Browser 로컬 managed policy 경계 종료 증거 — 2026-09-27

## 판정

`Completed` — 현행 Browser의 선택적 managed 설정과 Act proposal PDP
호환 경로에 대한 로컬 fail-closed 판정이다. `master`의 `27215a9e` 위에서
S11 미커밋 변경을 보존한 상태로 S12를 검증했다. 운영 Enterprise Identity,
RBAC, 중앙 승인 또는 PDP 배포 판정이 아니다.

## 구현과 검증 경계

- managed policy 키가 없으면 Community 로컬 경로를 사용한다. 키가 있으나
  값이 `null`/`false`/빈 문자열이거나 enterprise endpoint가 빠졌거나
  managed storage API가 없거나 읽기에 실패하거나 비정상 결과를 반환하면
  `ENTERPRISE_POLICY_UNAVAILABLE`로 막는다.
- PDP는 HTTPS endpoint로 쿠키 없이 `no-store` POST하며 identity의
  `organization_id`/`user_id`/`device_id`만 보낸다. 응답은 JSON 파싱 전
  8 KiB로 제한한다. DENY, outage, non-OK, 잘못된 schema와 과대 응답을
  거부한다.
- 인증·소비 경로가 없는 `managed_auto: true`와 `approval_token`은
  거부한다. Act executor는 주입된 ALLOW/`managed_auto: true`에도
  저장된 로컬 deny를 우회하지 않는 단위 테스트를 통과했다.
- 기존 Chrome S8 Side Panel 권한 경로에서 skip R1/R2, standard 복귀,
  저장된 deny, follow-plan exact scope와 만료를 재검증했다. 이 Chrome
  검사는 managed policy/PDP 연결 자체의 E2E는 아니다.
