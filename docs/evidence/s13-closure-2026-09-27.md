## 판정

`Completed` — Browser 로컬의 제한된 Act policy/terminal metadata와

## 구현·음성 검증

- `AuditEvent`를 실제 emit하는 `policy`/`terminal`로 축소하고,
  필드 allowlist, run/프로필/workflow ID, enum, error code와 정확한 HTTPS
  origin을 런타임 검증한다. raw `value`·`tool` 필드, URL path/query,
  알 수 없는 outcome/code는 전송 전에 거부한다.
- 최초 Act proposal과 value/confirmation 재인가에서 ALLOW, DENY,
  PDP 장애를 구분한다. Profile/workflow ID는 이름 공간별 SHA-256 해시로
  기록하고 원문을 이벤트에 복사하지 않는다.
- 실제 Act 종료 호출에서 `UNKNOWN`과 closed error code를 보존하고
  중복 terminal 이벤트를 만들지 않는다. 알 수 없는 error 문자열은
  audit body에서 제외한다.
- 선택적 sink는 쿠키 없는 `no-store` HTTPS POST를 사용한다. 설정 부재
  `SKIPPED`, HTTP 성공 `SENT`, 설정·저장소·네트워크·HTTP 실패 `FAILED`를
  반환한다. 원문 필드가 있는 이벤트는 HTTP 요청 전에 차단하고,
  전송 실패 시 행동 재실행이나 audit 재전송을 하지 않는다.
