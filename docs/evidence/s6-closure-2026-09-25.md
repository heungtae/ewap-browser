# S6 로컬 종료 증거 — 2026-09-25

## 판정 범위

[33번 현재 Ask 경로](../33-ask-request-execution-current-implementation.md)의
최초 semantic snapshot에서 읽는 `read_page`, `get_page_text`, `find`,
`read_batch`, 단일 활성 탭의 `tabs_context`, 선택 권한을 받은 viewport
`screenshot`과 같은 run의 `zoom`을 판정했다.
[S6 설계](../sprints/s6-advanced-page-reading.md)에 따라 다중 tab group,
5,000 node, rerank, CDP screenshot, annotation과 S6-R 전체 collection
수집은 이 로컬 종료 범위에서 제외한다.

## 구현 확인

- `read_batch`는 1~8개 모든 item의 tool·인수·상한·ref를 먼저 검사하고
  snapshot 읽기만 순서대로 실행한다. 취소·30초·3MB 경계를 검사한다.
- `get_page_text`의 content walk에서 CSS hidden, aria hidden,
  collapsed와 비표시 text를 제외한다. `all_dom` tree와 `find`는 hidden
  node를 visibility/reason과 함께 반환한다.
- 모델 screenshot은 `manual_or_model` policy와 활성 run tab을 확인한다.
  Chrome capture 권한 오류와 캡처 중 탭 전환은 fail closed로 처리한다.
  `zoom`은 fetch가 금지된 Service Worker에서도 transient JPEG를 Blob으로
  복원해 정규화 영역을 자른다.
- Settings는 선택형 `<all_urls>` 전체 사이트 접근 요청과 현재 상태를
  표시한다. HTTP Provider 전송은 이 넓은 권한만으로 허용하지 않고
  해당 HTTP host의 별도 grant가 필요하다. Chrome 확장 관리 화면에서
  전체 사이트 접근을 철회한다.

## 18번 계획과의 대응

| 영역 | 이 범위에서 확인한 것 | 현재 종료 조건에서 제외한 것 |
| --- | --- | --- |
| READ | Chrome schema v2/`all_dom`, visible heading/button, `display:none`·visibility·opacity·aria ancestor·collapsed reason, `visible_only`·`interactive`; unit focused depth/invalid args | 5,000 node와 `PAGE_READ_TRUNCATED` 계약. 현재 cap은 1,000 projection node |
| SEC-READ | HTTPS Provider 요청의 password·OTP·API key·storage·cookie·URL query/fragment·closed shadow·frame 내부 원문 부재. script source도 outbound에 없음 | screenshot 픽셀에 보이는 정보의 자동 마스킹 |
| FIND | Chrome hidden result와 ref/visibility, batch find; unit 20개 cap·visible scope·512자 query 거부 | rerank 모델, typo/fuzzy 의미 검색과 fabricated-ref fallback |
| VIS | Chrome 권한 없는 capture 거부, 권한 있는 active tab JPEG·zoom; unit 1.4MB·normalized region·policy disabled·탭 변경; run image release와 storage 비노출 | CDP `Page.captureScreenshot`, 여러 DPR·restricted URL·이미지 prompt injection에 대한 live-model 판정 |
| TAB/BATCH | Chrome 단일 run tab과 URL query/fragment 제거, 9개 UI tool card; unit title control char, batch 선검증·순서·취소·30초 | group ownership, 복수 tab 복구, screenshot을 batch 안에 넣는 경로 |

Chrome fixture의 page text에는 prompt injection 문장이 있지만 Provider는
통제된 결정적 응답을 사용했다. 따라서 이 실행은 모델의 주입 저항성을
증명하지 않는다. Provider에 mutation tool을 노출하지 않은 경계와
텍스트 결과의 금지 원문 부재만 확인했다. screenshot 픽셀에는 화면에
보이는 민감 정보가 들어갈 수 있어 선택 권한과 policy가 필요하다.

Chrome 자동화는 선택 권한을 격리 profile에 미리 부여했다. Settings의
브라우저 권한 대화상자 승인 자체와 live Provider·실제 사이트는 이
증거에 포함되지 않는다. S6 `Completed`는 위 로컬 Browser 범위만 뜻하며
S6-R collection reading 상태를 바꾸지 않는다.
